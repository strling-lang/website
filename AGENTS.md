# Agent navigation

## Repository ownership

This repository owns STRling's public website, user and learning content,
content integration, accessibility, browser behavior, SEO/GEO/AEO and machine
discoverability, and deployment configuration. It does not own language or
compiler truth (`strling`), empirical evidence (`regex-conformance`), research
conclusions (`research-intelligence`), or organization defaults (`.github`).

## Authority and entrypoints

- Start with [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
- Follow [docs/CONTENT_SOURCES.md](docs/CONTENT_SOURCES.md) for public claims,
  [docs/SEO_STRATEGY.md](docs/SEO_STRATEGY.md) for discoverability, and
  [docs/AI_DISCOVERABILITY.md](docs/AI_DISCOVERABILITY.md) for machine-readable
  content.
- Follow [SECURITY.md](SECURITY.md) for browser, supply-chain, content, and
  deployment boundaries.
- Read the nearest nested `AGENTS.md` before changing `src/content` or
  `src/data`.

Published claims must be supported by public/default-branch canonical sources
or live package records. A local branch, private plan, Notion-only state,
unadopted research recommendation, prepared package, or implementation intent
is not automatically public truth. Narrow or omit unsupported claims.

`dist/` is generated by Astro and must not be edited or committed. Change its
source content, data, components, or configuration. Deployment and external
Netlify settings require explicit authorization.

## Validation and working safely

Use the smallest relevant level:

```text
changed-file check
→ npm run check and affected lint
→ npm run build
→ npm test
→ npm run test:e2e for interaction, responsive, metadata, or accessibility work
→ deployment readiness
```

Do not run Playwright for a trivial content or instruction change. For visual
or interactive work, preserve semantic HTML, keyboard and focus behavior,
responsive layouts, reduced motion, and relevant axe coverage.

Inspect branch, status, staged changes, and recent history before editing.
`main` is deployable, but a commit does not authorize deployment. Preserve
concurrent work; stage exact paths only. Never deploy, push, merge, reset,
clean, change external settings, or rewrite history without explicit
authorization.

Copilot file scopes live in [.github/instructions](.github/instructions) and
reusable prompts in [.github/prompts](.github/prompts).
