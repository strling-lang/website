# STRling Lab and RegEx Lab feature inventory

## 1. Executive overview and exact baseline

The canonical `website` worktree is the source for this inventory and the local review of `/lab/` and `/regex/lab/`. It retains the entire history of reviewed usability commit `1de6d8da9b52e3e42b1efb9486ad4147bb739417` and adds final control alignment, disclosure spacing, full-sample Timing experiments, and non-destructive source navigation. The original 303-item inventory is preserved in the documentation-only commit `bc46c0d`. The local review receipt records the exact canonical revision, built files, and running preview. Deployable `main` remains at `ba07385ac80f12eb1b432a93e925e465a8887cd1` with the compiler-tools manifest in `sealed` mode. The local review uses `certified` mode to exercise the canonical formatter, converter, and no-match evaluator. The earlier detached work at `3187d307e1d4707d706b1a7508f0cc5c067cadac` is preserved in a separate worktree.

The earlier review previews at `https://127.0.0.1:46164` and `https://127.0.0.1:46166` record previous candidates. The Timing review at `https://127.0.0.1:46168` is historical. The current canonical preview uses `https://127.0.0.1:46184`. Compiles use released STRling 4.0.3. Canonical tools use the independently verified RC4 adapter, `strling-lab-wasm 0.1.0-rc.4`, protocol `strling.lab-compiler-tools@1.0.0-rc.1`, Wasm SHA-256 `266f3167537a40722682f436729468795a1672e3d277e5dac9237bd9c04d0181`. The local review uses frozen release assets and offline release metadata. Public-release availability is a separate gate. Browser observations in this document concern the selected browser, runtime, and input. Both Labs link to separate certified Regex Conformance evidence through RegEx Compatibility Check.

**Reading the tables.** Each current row has a stable ID, label or feature name, ownership, item type, behavior and output, availability, and verification. Retired control IDs remain in the earlier inventory revision. A subsection supplies the location unless the row identifies a narrower one. `SI` means **Shared — identical**, `SS` **Shared — specialized**, `SL` **STRling-only**, `RL` **RegEx-only**. Availability tags are `A` always offered in its owning interface, `C` conditional, `U` unavailable under the stated condition, `Ø` intentionally absent with no exposed control. A row may have multiple availability tags with one primary owner. UI output and material differences are recorded together in the behavior column. Capitalization follows the interface where it supplies a label.

**Evidence notation.** `W` is `src/components/lab/Workbench.astro`; `B` is `src/scripts/labWorkbench.ts`; `E` is `src/scripts/labEditor.ts`; `R` is `src/scripts/labRendering.ts`; `CSS` is `src/styles/workbench.css`; `H` is `src/components/SiteHeader.astro`, `SiteFooter.astro`, `Breadcrumbs.astro`, and `src/layouts/BaseLayout.astro`; `L:<name>` denotes `src/lib/regex-lab/<name>`; `T` refers to the accepted browser suite, principally `tests/e2e/regex-lab.spec.ts`. `I01`–`I13` identify retained baseline browser exercises in §14. Updated assertions in `T` cover the changed controls. The absence of an `I` or `T` marker means source inspection established that row or specific edge state. A marker verifies the applicable observed branch, while the adjacent source references cover additional branches and limits.

## 2. Complete STRling Lab map

The STRling route combines Semantic STRling and Simply authoring, canonical compilation in 4.0.3, five exact target profiles, and a separately identified tools adapter. The initial Semantic example compiles automatically while **Live** is off. **Run** and **Run artifact** invoke the eligible emitted pattern. See [configuration and editors](#8-top-level-controls-and-editors), [tab inventory](#7-primary-tab-by-tab-comparison), [results](#9-results-and-output-presentations), and [runtime matrix](#11-runtime-and-operation-capability-matrix) for the item records. Its unique controls and evidence are indexed in §5.

## 3. Complete RegEx Lab map

The RegEx route starts with a JavaScript raw pattern, a sample subject, and **Live** on. Its runtime control selects one of seven families/versions/modes and its separate flags field supplies raw engine flags. The Structure tab has ECMAScript parser and native PCRE2/Python variants. Compare adds a second-runtime experiment. See §§6–9 and 11 for every control and state.

## 4. Shared feature map

Both Labs use the same editor shell, subject datasets, replacement modes, tabs and keyboard navigation, operation selection, result and extraction presentation, tests, revision comparison, timing, and local session archive. The same UI surfaces receive different authority: raw engine output or preview of a compiled artifact, parser facts or compiler facts, and historical or freshly executed observations. Rows marked `SS` make each difference explicit. Both have Debugger and continuation surfaces; eligibility comes from the exact active runtime and result rather than the tab label. See §§7–13 for control-level records.

## 5. STRling-only feature map

`CFG-01` and `CFG-02` select authoring and output profiles. `ED-09` and `ED-10` format JSON or canonical source. `CMP-01`–`CMP-11`, `ART-01`–`ART-13`, and `SEM-01`–`SEM-15` inventory the compiler, artifact, conversion, and explanation UI. `RES-08` and `HL-17` link named captures to canonical source only while a corresponding live compiler program exists. RegEx can retain generated origin data, including original source, without acquiring these compiler actions.

## 6. RegEx-only feature map

`CFG-03`, `CFG-04`, and `CFG-05` are the raw runtime, flags, and per-engine help. `ST-01`–`ST-10` describe the raw Structure tab and its integration examples. `CP-03` and `CP-04` select and execute a second runtime. `HL-14` covers an engine-reported raw pattern offset. `RES-20` identifies generated origin on the receiving side of the one-way transfer.

## 15. Discrepancies between documentation, source, and rendering

### Baseline findings and refinement behavior

1. **Artifact handoff** now names sample transfer explicitly. Both handoffs retain the guarded same-tab transport and compiler origin. Only the cursor action carries a saved scan boundary. The destination opens paused.
2. **Session download** includes all available snapshot data. File imports create separate working copies and save under new local session IDs. The settings link retains its existing allowlist.
3. **Native Structure** preserves a completed valid inspection across tab visits. A change in source, flags, engine or applicable native newline option requires a fresh inspection.
4. **Working copies and revisions** now have separate storage keys and lifecycles. Deleting a working pattern or dataset cannot remove a revision. Neither working-copy restoration nor reading a recorded observation produces a new runtime result.
5. **Compiler scope** is unchanged. The preview uses the same verified RC4 bytes. The PCRE2 notices remain downloads, and the 8,192-unit editor source cap follows the pinned native buffer described in the workbench notes.

### Deliberate limits and non-findings

- A disabled trace control for JavaScript or Python, a missing Python structure-node range, and non-navigable byte ranges within a UTF-8 scalar reflect capabilities of the real providers and display model. PCRE2 `partial` and CPython `parsed` refer to structure authority, independently of runtime observations.
- Compiler/Structure, concrete native Results, and canonical Semantic tools each have separate authority. A parser error, emitted-profile refusal, runtime failure, and canonical `unavailable` are observable but different states. The label match does not establish parity between them.
- The raw UI lacks a peer STRling conversion action, and STRling lacks same-source multiple-engine comparison and raw engine flag selection. These are absent controls; they do not become enabled by loading an artifact or revision.
- This inventory reflects the refined UI. The preview exercises the original compiler behavior and frozen adapter bytes under the existing release policy. Public RC4 acquisition is outside the local evidence.
