# Public-content agent guidance

`src/content/` owns public Docs and Learn collection source. Read
[../../docs/CONTENT_SOURCES.md](../../docs/CONTENT_SOURCES.md), the relevant
collection schema/configuration, and nearby content before editing.

Trace consequential claims to the appropriate public/default-branch source or
live registry record. Do not publish private plans, Notion-only status,
branch-only work, unadopted research recommendations, uncertified package
availability, dates, versions, or guarantees. Distinguish exact verified output
from conceptual output shape and keep Fourth Edition language explicitly
provisional through the central release data.

Preserve meaningful headings, stable links, static-HTML usefulness, code
context, target-engine assumptions, and collection metadata. Update shared data
instead of duplicating a release, binding, repository, URL, or navigation fact
in page copy. Run the changed-file checks, Astro check, build, and relevant
content/link tests; browser tests are required only when rendered behavior is
affected.
